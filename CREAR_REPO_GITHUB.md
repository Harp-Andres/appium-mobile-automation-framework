## 🔧 Pasos para Crear el Repositorio

### Opción 1: Desde la Web de GitHub (Recomendado)

1. **Ve a GitHub:** https://github.com/new

2. **Completa el formulario:**
   - **Repository name:** `appium-mobile-automation-framework`
   - **Description:** `🤖 Framework profesional de automatización móvil con Appium + Cucumber + JUnit5 + Allure Reports | POM + BDD | Android & iOS | CI/CD Ready`
   - **Visibility:** Público ✅ (recomendado para portfolio)
   - **NO** marques "Initialize with README" ❌ (ya lo tienes)
   - **NO** agregues .gitignore ❌ (ya lo tienes)
   - **NO** agregues licencia ahora ❌ (puedes hacerlo después)

3. **Clic en "Create repository"**

4. **Copiar los comandos que GitHub te muestra:**

---

### 🔗 Conectar tu Repositorio Local con GitHub

Después de crear el repo en GitHub, ejecuta estos comandos en tu PowerShell:

```powershell
# 1. Navegar al proyecto
cd "E:\UnidadPrincipal\Documentos\ProyectosAutomatizacionModerna\appium-cucumber-base"

# 2. Agregar el remoto (REEMPLAZA "TU-USUARIO" con tu usuario de GitHub)
git remote add origin https://github.com/TU-USUARIO/appium-mobile-automation-framework.git

# 3. Cambiar el nombre de la rama a main (convención moderna)
git branch -M main

# 4. Subir al repositorio
git push -u origin main
```

**⚠️ Importante:** Reemplaza `TU-USUARIO` con tu usuario real de GitHub.
